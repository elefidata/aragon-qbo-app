# Aragon Books AI — public policy pages

Static pages for Intuit's QuickBooks Online production-app questionnaire
(launch URL, disconnect URL, EULA, and privacy policy).

These pages describe an **internal-only** tool used by Aragon Group Inc
(Calabasas, California) to categorize the company's own books. They do not
sign anyone in or display financial data.

Published with GitHub Pages from this repository's `main` branch (site root).
Source is also kept in the `qbo-daily-tagger` project at
`docs/intuit-app-pages/`.
